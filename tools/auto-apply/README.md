# IoT 求职雷达 — 半自动投递脚本

自动打开各平台投递页,并**自动预填通用信息**,由你人工确认提交。用于官网 + 聚合平台(智联/牛客/实习僧等)。

> ⚠️ **重要风险提示(请先读完)**
> 1. 请遵守各招聘平台用户协议与网站规则;高频全自动批量投递可能触发风控,导致**账号被限流或封禁**,风险由使用者自担。
> 2. 本脚本**不会**绕过验证码/滑块、不会静默自动点击提交——所有提交动作由你亲自完成,页面保持可见。
> 3. 每天最多投递 `config.json` 中 `daily_limit` 配置的数量(默认 10),每次操作间隔随机 3~8 秒。
> 4. 简历信息请务必真实,虚假信息可能被企业拉黑。

## 安装(Windows / macOS / Linux)

```bash
# 1. 需要 Python 3.8+(本项目在 Python 3.14 下开发)
pip install -r requirements.txt

# 2. 安装 Playwright 浏览器内核(首次约 100MB)
playwright install chromium
```

## 配置

编辑 `config.json`:

- `resume`:你的基本信息(姓名/电话/邮箱/学校/专业/毕业年份),脚本用这些字段自动预填;
- `targets`:投递目标数组,每项 `{ "name": 名称, "url": 投递页链接, "note": 备注 }`。可自行增删;
- `daily_limit`:每日投递上限。

**在 config.json 的 targets 里填入你要投递的公司投递页链接**(各公司校招官网网申页,或智联/牛客等聚合平台的岗位页),保存后运行脚本即可。

## 运行

```bash
# 先看一遍计划(不打开浏览器)
python auto_apply.py --dry-run

# 正式运行
python auto_apply.py
```

运行过程:

1. 浏览器以**有头模式**打开每个投递页;
2. 脚本按 label/placeholder 文本匹配,自动预填姓名/电话/邮箱/学校等通用字段(填不上的跳过);
3. **停住,由你**核对信息、完成验证码、补填复杂字段、点击提交按钮;
4. 按回车进入下一个目标,直到完成或达到每日上限。

## 常见问题

- **表单字段没填上?** 各平台表单字段文案差异大,脚本只做文本匹配预填;填不上的手动补即可,不影响使用。
- **可以全自动无人值守吗?** 不建议也不支持:不做验证码绕过、不自动提交,这是对账号安全的保护。
- **投递记录在哪?** `applied_today.txt` 记录当天已处理的目标;网页端「投递工作台」可跟踪每家公司的完整进度(已投递/笔试/面试/Offer)。

## 扩展

想针对某个平台做更精细的自动填写,可参考 `sites_example.py` 中的平台表单说明与示例选择器,自行扩展 `fill_common`。
